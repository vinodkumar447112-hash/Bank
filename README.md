# Bank — Java OOP Project

A simple console-based banking application built using Java with Object-Oriented Programming concepts.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Apply for a loan
- Check outstanding loan amount
- View account details
- Change account PIN
- Transfer money between accounts

## Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Constructors
- Method Overloading
- Access Modifiers
- ArrayList
- Conditional Statements and Loops

## Technologies

- Java
- Git and GitHub

## How to Run

1. Clone this repository.
2. Open the project in your Java IDE.
3. Compile the Java files.
4. Run the main class.
5. Follow the console menu.

## Current Limitations

- Account data is stored in memory and is lost when the program exits.
- MySQL database integration is not implemented yet (planned for later).

## Future Improvements

- MySQL database integration
- Transaction history
- Persistent account storage
